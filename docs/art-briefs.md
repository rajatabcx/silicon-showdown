# Character art briefs

Each character starts as one drawn concept image. That image goes into the image-to-3D tool, so it has to follow the rules below or the model comes out broken.

## Rules for every concept image
- **Full body, head to shoes, nothing cropped.** Standing straight, facing the camera.
- **A-pose:** arms held straight and about 45° away from the body, palms down, fingers apart. Legs slightly apart.
- **Plain light-grey background.** No floor shadow, no props, no text, no logos.
- **Style:** editorial ink caricature. Thick black outlines, flat colours with one shadow tone, no gradients, no photo texture. Ugly-funny, not cute.
- **Proportions:** adult body about 5 heads tall (so the head is about 1.5× real size). Features pushed hard, but the person must be recognisable in silhouette.
- An original drawing. Not traced from a photo, and not in the hand of any particular living artist.
- A second image of the same character from the **side** helps, in the same pose and style.

# Image prompts: sidekicks, remaining fighters, boss

Reference for the look: `docs/concepts/tusk_sheet.png` and `docs/concepts/teal_sheet.webp`. Attach one of them to the image tool as a style reference where it allows that.

**How to use:** paste the style block, then one character block, as a single prompt. Feed the front view (or front + side + back) to the image-to-3D tool.

## Style block (paste first, every time)

> Character turnaround sheet of one original cartoon character. Four full-body views in a row on a plain light-grey background: front view, three-quarter view, side profile, back view. Same character, same clothes and same proportions in all four. Front and back views are in an A-pose: arms straight, held about 45° away from the body, palms down, fingers apart, legs slightly apart, feet flat. Head to shoes visible, nothing cropped. Editorial ink caricature: thick black outlines, flat colours with one shadow tone, no gradients, no photo texture. Ugly-funny, not cute. Oversized head, body about 4.5 heads tall. Mouth closed. Empty hands. No props, no text, no logos, no floor shadow.
